      Spend guard & pinned diskspd verification

      Under the family spend rule, any mode that provisions or starts cloud resources requires -SandboxBatchApproval "go batch <id> $<total>". When storage-fslogix-io runs with a local diskspd binary, Test-AvdDiskSpdBinary verifies its SHA-256 hash against the pinned MIT allowlist before execution.

      Validate & Submit Evidence (C25)

      Validate a local C25 JSON file in your browser and open a prefilled GitHub Issue Form on avd-assess.

      Open prefilled avd-assess issue form
      What the browser validator checks

      The validator checks that every environment property uses closed enums and public VM SKUs, sample counts use privacy bands (1-2, 3-9, 10-25, 26-100, 100+), metrics hold only aggregate percentiles or scalars, and the JSON contains no GUIDs, email addresses, IPv4 addresses, UNC paths, Azure resource IDs, or private domain names.
